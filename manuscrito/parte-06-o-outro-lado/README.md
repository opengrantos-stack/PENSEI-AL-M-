# PARTE VI — O OUTRO LADO

## O que a inteligência artificial não deve fazer por você

Esta parte aborda os limites, riscos e responsabilidades relacionados ao uso da inteligência artificial.

O objetivo não é criar medo da tecnologia, mas ensinar o leitor a utilizá-la com pensamento crítico, responsabilidade e consciência.
